# Harna logosi

Ikki bir-biriga ulangan halqa. Yuqori kesishishda mis rangli halqa ustda
(atrofida ingichka oraliq bilan), pastkisida grafit halqa ustda.

## Ranglar

| Rang | Kod | Qayerda |
|---|---|---|
| Mis | `#B66D3B` | chap halqa (oq fonda) |
| Grafit | `#212A2B` | o‘ng halqa (oq fonda) |
| Mis, to‘q fon uchun | `#C47A45` | chap halqa (to‘q fonda) |
| Och kulrang | `#EEF1F2` | o‘ng halqa (to‘q fonda) |

## Fayllar

| Fayl | Nima uchun |
|---|---|
| `harna-logo.svg` | asosiy logo, oq va och fonlar uchun (281 bayt) |
| `harna-logo-on-dark.svg` | to‘q fonlar uchun |
| `harna-favicon.svg` | brauzer yorlig‘i; tizim to‘q rejimida o‘ng halqa o‘zi oqaradi |
| `harna-icon-512.png`, `harna-icon-192.png` | ilova ikonkasi (oq, burchaklari yumaloq) |
| `harna-icon-maskable-512.png` | Android uchun «maskable» ikonka (to‘liq oq fon, belgi xavfsiz zonada) |
| `harna-apple-touch-icon.png` | iPhone/iPad bosh ekrani (180×180) |
| `harna-logo-1024.png`, `harna-logo-on-dark-1024.png` | hujjat va taqdimotlar uchun shaffof PNG |

Iloji bo‘lsa SVG ishlating: u har qanday o‘lchamda tiniq va eng yengil.

## Geometriya

`viewBox="0 0 107 68"`: ikki halqa, o‘rta radiusi 29, qalinligi 10 (tashqi
radius 34), markazlari (34, 34) va (73, 34). Oraliq — har tomonda 1,5.
Logo atrofida kamida bitta halqa qalinligicha bo‘sh joy qoldiring.
